# Student Career Hub

Student Career Hub is a web-based platform designed to help students prepare for their careers and campus placements.

## 🚀 Live Website

https://thogurubhargavi-png.github.io/Student-Career-Hub/

## ✨ Features

- Career roadmaps for different career paths
- Java coding practice
- Aptitude practice
- Skill learning and progress tracking
- Resume builder
- Placement readiness dashboard
- Progress saved using browser local storage
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages

## 📚 Project Sections

### Career Roadmaps
Provides roadmaps for:
- Data Analytics
- Software Development
- Web Development

### Coding Practice
Students can practice basic Java programming questions and track their scores.

### Aptitude Practice
Students can practice quantitative aptitude questions and view their scores.

### Skills
Users can track their learning progress in:
- Java
- SQL
- Python
- Power BI

### Resume Builder
Users can enter their details and generate a printable resume.

### Placement Readiness Dashboard
The dashboard combines practice scores, skill progress, and resume completion to provide an overall readiness percentage.

## ▶️ How to Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server.
